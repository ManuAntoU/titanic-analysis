# 🚢 Titanic Data Analysis — Day 1

A beginner-friendly exploratory data analysis (EDA) project on the famous **Titanic dataset** using Python, Pandas, and ydata-profiling.

---

## 📌 Project Overview

This notebook covers the foundational steps of data analysis on the Titanic dataset — one of the most well-known datasets in data science. The goal is to understand the structure of the data, explore key statistics, and generate an automated profiling report.

---

## 📂 Files

| File | Description |
|------|-------------|
| `Day1_Titanic_Analysis.ipynb` | Main Jupyter/Colab notebook with analysis |
| `Titanic_Profiling_Report.html` | Auto-generated ydata-profiling report |

---

## 🛠️ Tools & Libraries Used

- **Python 3**
- **Pandas** — data manipulation and exploration
- **ydata-profiling** — automated EDA report generation
- **Google Colab** — development environment

---

## 📊 What's Covered

- Loading and previewing the Titanic dataset
- Exploring data types, shape, and basic statistics
- Understanding missing values and column distributions
- Generating a full **ydata-profiling report** with interactive insights

---

## 🚀 How to Run

1. Open the notebook in [Google Colab](https://colab.research.google.com/) or Jupyter Notebook.
2. Install dependencies:
   ```bash
   pip install ydata-profiling
   ```
3. Run all cells to generate the profiling report.

---

## 📈 Dataset

The Titanic dataset contains information about passengers aboard the RMS Titanic, including survival status, class, age, fare, and more.

- **Source:** [Kaggle Titanic Dataset](https://www.kaggle.com/c/titanic/data) / Seaborn built-in dataset
- **Rows:** 891 passengers
- **Key Columns:** `Survived`, `Pclass`, `Name`, `Sex`, `Age`, `Fare`, `Embarked`
